# Trupe Peniel — Landing Page

Página institucional da **Trupe Peniel**, ministério de palhaçaria humanitária da Peniel Church.

A identidade visual segue a **logo oficial da Trupe Peniel**: fundo preto, branco e o vermelho do nariz, com a caligrafia e o palhaço da marca.

---

## Como ver a página no seu computador

1. Abra a pasta `Trupe da Peniel`.
2. Dê dois cliques no arquivo `index.html`.
3. A página abre no navegador.

---

## Como colocar no GitHub (passo a passo, do zero)

O GitHub é um site gratuito para guardar sua página. O GitHub Pages é o serviço que a transforma em um endereço na internet, que você pode mandar para as pessoas.

### 1. Criar sua conta

1. Acesse [https://github.com/signup](https://github.com/signup).
2. Informe um e-mail seu.
3. Crie uma senha.
4. Escolha um nome de usuário (exemplo: `trupepeniel` ou seu nome).
5. Confirme o e-mail que o GitHub enviar.

É gratuito. Não precisa pagar nada para esta página.

### 2. Criar o “repositório” (a pasta online)

1. Depois de entrar, clique no **+** no canto superior direito.
2. Clique em **New repository**.
3. Em **Repository name**, escreva: `trupe-peniel`.
4. Deixe marcado **Public** (precisa ser público para a página ficar visível).
5. **Não** marque “Add a README”.
6. Clique em **Create repository**.

### 3. Enviar os arquivos

Na tela nova, clique em **uploading an existing file**.

1. Abra a pasta `Trupe da Peniel` no seu computador.
2. Arraste para o GitHub estes itens:
   - `index.html`
   - `css`
   - `js`
   - `assets`
   - `README.md`
3. Role até o fim da página.
4. Clique em **Commit changes**.

### 4. Ligar a página pública

1. No repositório, clique em **Settings**.
2. No menu da esquerda, clique em **Pages**.
3. Em **Branch**, escolha **main** e a pasta **/ (root)**.
4. Clique em **Save**.
5. Espere cerca de 1 minuto.
6. Atualize a página. Aparecerá um endereço assim:

`https://SEU-USUARIO.github.io/trupe-peniel/`

Esse é o link da Landing Page. Guarde e compartilhe.

## O que você ainda precisa preencher

Abra o arquivo `js/config.js` e cole os dados oficiais:

- número de WhatsApp
- Instagram, Facebook e YouTube
- chave Pix (quando existir)
- números de impacto (ações, pessoas, instituições…)

Na própria página, onde está escrito **[INSERIR …]**, depois você (ou eu) troca por:

- história oficial da Trupe
- fotos reais
- depoimentos reais
- nomes dos palhaços

**Não invente** depoimentos, números ou fotos. A página já nasceu preparada para receber o que for verdadeiro.

### Fotos

Crie a pasta `assets/fotos` e coloque:

- `hero.jpg` — foto grande de um encontro real (aparece atrás do título inicial)

As demais fotos da galeria podem ser ligadas depois. Me chame quando tiver as imagens que eu encaixo para você.

### Logo

A logo oficial da Trupe Peniel está em `assets/logo-trupe-peniel.png` e aparece no topo, na primeira dobra e no rodapé.
